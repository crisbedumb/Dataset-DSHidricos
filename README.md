# Dataset-DSHidricos
- Archivo: DSHidricos_Dataset.csv
- Conjunto de datos: Distritos declarados en estado de emergencia por riesgos asociados a recursos hídricos.
- Entidad: SUNASS
- Fuente: https://www.datosabiertos.gob.pe/dataset/distritos-declarados-en-estado-de-emergencia-por-riesgos-asociados-recursos-h%C3%ADdricos-sunass 
- Fecha de publicación: 2026-09-15
- Fecha de descarga: 2026-11-23
- Licencia: Open Data Commons Attribution License
- Uso en el proyecto: columnas DISTRITO, ANIO, COB_AGUA y CONT_HD,
  leídas por n8n para evaluar el estado del servicio de agua.
- Criterio de alerta (definido por el grupo, no es una norma oficial):
  continuidad menor a 12 horas al día o cobertura menor a 80 %.
